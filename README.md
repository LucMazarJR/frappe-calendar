# Projeto: Calendário de Agendamentos (Frappe Framework)

Este é um projeto simples desenvolvido com **Frappe Framework**, com o objetivo de criar uma view de calendário e implementar a lógica de validação para agendamentos. A aplicação utiliza **Python** (server-side) e **JavaScript** (client-side).

## 🚀 Funcionalidades

- 📅 Visualização de eventos em um calendário.
- ✅ Validação de regras de agendamento (ex.: evitar conflitos de horário).
- 🔄 Integração entre frontend (JS) e backend (Python) usando o framework Frappe.

## 🛠 Tecnologias utilizadas

- [Frappe Framework](https://frappeframework.com/)
- Python 3
- JavaScript (custom scripts)
- HTML/CSS (via Frappe templating)
- MariaDB / MySQL (via Frappe ORM)
